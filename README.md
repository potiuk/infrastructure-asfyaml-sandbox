# infrastructure-asfyaml-sandbox

Throwaway sandbox for testing changes to the
[`.asf.yaml` parser](https://github.com/apache/infrastructure-asfyaml).

Its settings, branch protections, labels and rulesets exist to be mangled and
reset. Nothing here is real.

`main` holds the baseline `.asf.yaml` — "settings at rest". See
[docs/testing-a-change.md](https://github.com/apache/infrastructure-asfyaml/blob/main/docs/testing-a-change.md).
